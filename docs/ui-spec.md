# UI 사양

## 톤

- 블랙 기반 제작 콘솔
- 골드는 CTA와 핵심 신호에 제한적으로 사용
- 상태를 색상만으로 구분하지 않음
- 긴 그림자보다 얇은 보더와 밀도 조절을 우선
- 데이터 숫자는 tabular numerals 사용

## Home

첫 질문: **“다음 뮤직비디오를 무엇으로 만들까요?”**

사용자는 30초 안에 Rising signal을 확인하고 Recipe Builder로 이동해야 합니다.

## Recipe Builder

데스크톱:
- 좌: 5개 제작 축
- 중앙: 기법 선택
- 우: Live Evaluation

모바일:
- 제작 축 가로 스크롤
- 기법 카드 단일 컬럼
- 하단 고정 결과 바

## 언어

설명과 액션은 한국어로 작성합니다. 데이터 원문 식별자가 중요한 고유 기술명은 영문을 유지합니다.
