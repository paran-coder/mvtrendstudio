# UI 사양

## 톤

- 블랙 기반 제작 콘솔
- 골드는 CTA와 핵심 신호에 제한적으로 사용
- 상태를 색상만으로 구분하지 않음
- 긴 그림자보다 얇은 보더와 밀도 조절을 우선
- 데이터 숫자는 tabular numerals 사용

## Home

첫 질문: **“다음 뮤직비디오를 무엇으로 만들까요?”**

사용자는 30초 안에 Rising signal을 확인하고 Recipe Builder로 이동해야 합니다.

## Recipe Builder

데스크톱:
- 좌: 5개 제작 축
- 중앙: 기법 선택
- 우: Live Evaluation

모바일:
- 제작 축 가로 스크롤
- 기법 카드 단일 컬럼
- 하단 고정 결과 바

## 언어

설명과 액션은 한국어로 작성합니다. 데이터 원문 식별자가 중요한 고유 기술명은 영문을 유지합니다.

## User Guide / Onboarding — alpha.4

- `/guide`는 문서형 도움말보다 **실습형 3분 가이드**로 구성합니다.
- Home은 첫 5초 안에 `트렌드 → 조합 → 점수 → 근거` 흐름을 보여줍니다.
- Guide에는 Recipe 01–03을 전환하는 인터랙티브 샘플과 Builder 진입 CTA를 둡니다.
- Builder 상단에는 `5가지만 선택하세요`라는 짧은 인라인 가이드를 유지합니다.
- Score Panel에는 `?`를 두어 `/guide#score`로 바로 이동할 수 있게 합니다.
- `포화도 안전성`은 점수가 높을수록 더 안전한 값이라는 방향성을 문구로 명시합니다.
- 데스크톱 헤더에서 일반 탐색과 핵심 CTA를 분리합니다. `트렌드 / 감독 DNA / 분석 방법 / 사용자 가이드`는 일반 메뉴, `레시피 빌더`는 별도 CTA입니다.
