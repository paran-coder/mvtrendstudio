# 정보 구조

## 핵심 흐름

```text
Home / Trend Radar
      ↓
Recipe Builder
      ↓
Recipe Result
      ↓
Director DNA / Methodology
```

## 현재 라우트

```text
/                       홈 / Trend Radar
/trends                 트렌드 전체
/recipes/build          레시피 빌더
/recipes/result         생성 결과
/directors              감독 DNA
/methodology            분석 방법
```

## 추후 라우트

```text
/directors/[slug]       감독 상세
/recipes/[id]           저장된 레시피
/evidence/[id]          근거 장면 상세 또는 Drawer 기반 표현
```
